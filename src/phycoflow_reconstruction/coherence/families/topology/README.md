# Reserved Topological Coherence Family

This package reserves the peer family name `topology`; it intentionally has no
placeholder loss. A future contribution must define its topological objects,
filtration or threshold policy, connectivity and masks, physical-domain
semantics, invariances, units, differentiability, optional dependencies,
computational cost, failure cases, and degenerate examples before registration.

Topology components will define their own internal taxonomy rather than being
forced into the global-distribution `self/mutual/cross` subdivision.
