# Reconstruction examples

This tracked gallery stores selected, review-ready reconstruction figures used by the project
documentation. Routine generated figures remain under ignored case run directories.

## Current examples

- `senseiver_test_snapshot_0000_last.png`: turbulent-combustion Senseiver reconstruction from
  `tc_senseiver_5000ep/20260828T190145Z_fea0fc25`, using `last.pt` and test snapshot index `0`.
- `senseiver_test_best_relative_l2_violin.png`: field-wise relative-L2 distributions for 200
  evenly spaced test snapshots from the same Senseiver run, using `best.pt`.

Add future examples with descriptive, stable filenames and record their source run, checkpoint,
split, and snapshot index here.
