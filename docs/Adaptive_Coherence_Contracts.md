# Adaptive coherence contracts

This package extends the scalable C8 observer with bounded TRAIN discovery and explicit generative execution contracts. It is opt-in research infrastructure. Numerical qualification, sampler efficiency and learned-output adoption are separate decisions; implementation does not establish a learned benefit.

## Sources, support and risk

`source.admission: frozen_snapshot` requires a hash-bound snapshot receipt. `source.weight_view: ema_materialized` strictly loads the checkpoint and its auxiliary EMA, copies the selected EMA parameters into the live model, preserves buffers, and disables child EMA. The frozen SOURCE anchor denotes that same function. This starts a new child optimizer rather than resuming pretraining.

Native EDM uses complete structured-grid execution with its declared solver and clamping through `observation_consistency.mode: native`. Scoring native support and gathering a qualified selected support are different observables. An unqualified native-basis bridge is rejected. Rectified-flow activation checkpointing preserves the native velocity calculation and random state.

`physical_ensemble_risks` returns member risk and signed corrected mean risk using physical quadrature or declared sampling correction. For J2, mean risk equals the physical inner product of the two member errors. `physical_mean_risk_model_units` uses `MeanRiskDifferenceBudget`: an absolute SOURCE-relative difference, explicit absolute allowance and positive independent `mean_risk_scales`. Its signed SOURCE estimate is never used as a denominator. Formal member-risk experiments remain a separate contract.

## Finite representations and proposals

State retains all unary occupation measures and the frozen mixed directions in one complete norm. Scale retains its complete signed joint/piece-mean and log-power anchors. Added signed group projections and centered distinct-field triple descriptors are complete fair-score leaves outside those norms. The selected bank is a changed finite target, not an unbiased estimate of all possible interactions.

`adaptive_fitting.py` streams the declared approximately 10% TRAIN SOURCE panel. It records candidate identities, discrepancy, repeatability, sketch-based complementary sensitivity, cost and redundancy exclusions. Every supplied member contributes to the C8 comparison anchor. Complementary gradient sketches are ranking evidence and do not prove that the full joint anchor is inadequate.

Formal children declare `adaptive.bank_artifact: {path, sha256}` to consume the exact preformal JSON bank without rediscovery. Its fitted-input binding checks SOURCE members, references, coordinates, measures, normalizer, population, support and the shared C8 body; the bank retains its representation units and qualified policy fields.

`HierarchicalQuerySampler` uses implicit pair indices, a canonical tree path, a positive uniform mixture and bounded sparse state. Complete outer IDs carry actual probabilities and multiplicities. Shape also records conditional sign/line probabilities; duplicate outer IDs retain the specified shared-inner semantics. Importance correction precedes nonlinear optimizer composition and does not establish unbiased ConFIG or AdamW updates.

`allocate_cost_counts` rounds the continuous fixed-cost allocation `n_h = max(1, lambda * W_h * sigma_h / sqrt(c_h))` with active-stratum minima. It guarantees the charged budget and uses affordable marginal variance reduction for rounding; it does not claim integer optimality. The older `allocate_counts` is a draw-cap heuristic.

`profile_car_allocator.py` measures synchronized incremental bundles and audits true parameter gradients using a disk-backed exact Gram matrix. The currently qualifiable policy is the fixed SOURCE probability vector actually audited on both source families. Its profile identity, uniform floor and probabilities are checkpointed. The changing online policy remains unqualified and disabled. Failed efficiency or overhead gates retain uniform sampling of the same expanded target.

## Exact observer and lifecycle

`FrozenCoherenceObserver.score_tensors` shares differentiable scoring with detached assessment. It compiles immutable reference sorts, spectral statistics and persistence diagrams, while constructing endpoint-dependent merged CDF breakpoints from actual endpoints. It supports J1 paired scoring and every supplied conditional member for J>=2. `compiled=False` provides the same-target reference path. Neither path retains live graphs between calls.

State reference compilation follows the same physical-mass normalization arithmetic as the independent path. Compiled Shape reuse is restricted to assessment without gradients: batched persistence projections can select different finite-precision subgradients when the merged query pack changes shape. Differentiable observation uses the qualified per-pack Shape route while retaining State and Scale reuse. This preserves the training-gradient contract and does not claim a compiled Shape training speedup.

Artifacts bind source, fields, units, physical support, reference values, geometry, normalizer, bank and scientific source files. Pooled Shape rejects changed source-file hashes even when an unrelated definition changed in the same file. Run fitting, training, profiling and assessment from the matching immutable execution capsule; refit after a source identity changes. Do not relabel stale artifacts.

Sampler/calibration cursors commit only with accepted updates. Recovery restores scientific random streams and trims coupling journals to the checkpoint cursor. A budget pause saves full recovery state and curves. If it lands at a milestone, it saves that checkpoint and defers the panel until resume, before another update.

`checkpointing.save_epoch_zero: true` captures the materialized child before its first update. `checkpointing.panel_milestones_only: true` separates expensive panel callbacks from rolling recovery saves. Loss curves still refresh first when history exists, every ten completed epochs, at validation, pause and completion.

Evaluation can declare exact `sample_indices`, `sensor_counts`, `sensor_seed` and `members`. This leaves the native variable-count training protocol intact. A fixed panel is approximately 10% of the split by default, and compared outputs use matched condition, sensor, prior and member streams.

## Campaign tools and evidence

`run_coherence_adaptive_repair.py` binds immutable sources, execution code, additive GPU leases, forecasts, the six-hour closeout reserve and formal arm configurations. Its formal command requires the prescribed 1000 reporting epochs, thirteen B32 updates per epoch, all milestone checkpoints, shared C8 artifacts and the shared risk/C0 reference.

Case-owned `execution_constraints.json` records later owner instructions restricting devices or pausing a backend. GPU launch tools check it before scientific imports. A paused backend requires explicit owner continuation; CPU preparation does not authorize another model run.

`assess_car_checkpoints.py` streams native J4 endpoint banks, separates full-support decoded field risk from the declared core support, and freezes TRAIN-only finite alpha nominations. VALIDATION access requires both completed FFM arms and all twelve checkpoint-wise TRAIN nominations in a checked assessment freeze. The reserved task is final-epoch evidence only. EDM has a separate native-support execution-qualification mode without an efficacy or alpha-adoption claim.

`representation_contracts.py` includes zero-weight retained modes in the conditioning constant and reports when an inverse is unavailable. Its threshold-margin diagnostic accepts explicit mixed strict/non-strict operators. Bounds use pointwise distances and unresolved residuals; a fair score cannot replace either. Case receipts must supply the real constants, margins and population results before a task-sufficiency claim is considered.
