## 1. Outcome, scope and decisions

Answer one practical question: **can direct native ground-truth supervision plus finite State/Scale/Shape supervision improve unoptimized scientific relationships while retaining field accuracy, at a substantially lower training cost than the recent repair route?** Bundle the inexpensive related optimization and computation checks before one mature comparison. Do not reopen teacher–student training, add another reconstruction family, redesign SSS, or perform deployment benchmarking.

The mature paths are `Native_GT_Continuation` and `Native_GT_SSS_Safeguarded_Continuation`, initialized from the same immutable FFM SOURCE. The first is ordinary continuation with the model's original supervised objective. The second combines that objective with SSS in one backward pass, qualified exact computation reuse, a qualified query estimator if warranted, and a finite field-action filter. This compares the complete enhancement package against ordinary continuation; it does not isolate the causal contribution of SSS, the filter, and the estimator separately. Historical Round 3 provides context, not a third mature arm.

The intended endpoint is a 100-reporting-epoch learning review followed, when informative, by a 500-reporting-epoch maximum. The total proposed ceiling is **45 occupied GPU-hours across both devices and all attempts**; the expected spend must be updated downward or upward from short complete-epoch measurements before launch. GPU0 is primary; GPU1 may run independent ready work. A two-GPU-hour initial diagnosis plus at most two additional GPU-hours for a demonstrated correction bounds preparation. This is not a promise that the engineering work or the learning will succeed.

Make separate decisions about exact computation reuse, Shape estimation, startup/update validity, and learned-model adoption. Useful engineering can survive a failed learned candidate. A smoother loss plot alone cannot qualify a reconstruction. If neither learned output qualifies, retain SOURCE/C8 and close this round without another solver, weight search, teacher, or epoch extension.

## 3. Mathematical contract and its code realization

### 3.1 LPC motivates complementary finite observables

The [LPC theory](../../../Coherence_Manuscript_Foundation/01_Theory/LPC_THEORY.md) partitions mixed cumulants under its stated analytic assumption. SSS is a finite, overlapping collection of observable representations motivated by that theory; State, Scale and Shape are not respectively identical to Local, Pair and Collective, and they do not constitute a complete physical-law test. Field accuracy does not determine every joint-state error at finite error, but this does not guarantee useful optimization from an arbitrary SSS direction.

Retain current physical masses, masks, units, field order, full joint State/Scale anchors, mean and signed spectral information, selected bank, inner calibration, boundary conditions, persistence dimensions and member independence. State concerns represented joint value occupation; Scale concerns represented signed spatial organization; Shape concerns represented excursion topology. A location-specific held-out scientific relationship is essential because occupation and persistence can improve while spatial utility worsens.

For each family, preserve the current conditional finite-ensemble scoring contract, schematically

$$\widehat S_k=\frac1J\sum_j d_k(\Psi_k(X_j),\Psi_k(Z))-\frac1{J(J-1)}\sum_{j<\ell}d_k(\Psi_k(X_j),\Psi_k(X_\ell)).$$

This notation summarizes the attraction/separation construction, not permission to replace each family's implemented components by a new distance. Use independent J2 training members and differentiate through both. Keep J4 native assessment unchanged. Expected-score identification only concerns the represented law under the relevant distance and sampling assumptions; no universal full-field, causal, or PDE guarantee follows.

### 3.2 Direct native objective, with one model backward

For FFM, retain the existing native conditional flow-matching loss with the original conditioning and bridge conventions:

$$x_t=(1-t)x_0+tZ,\qquad L_{\rm native}=\mathbb E\|v_\theta(t,x_t,Y)-(Z-x_0)\|^2.$$

The exact adapter masking, normalization and observation semantics govern this schematic expression. Do not replace it with paired endpoint member MSE: that penalizes conditional spread differently. Native supervision, signed conditional-mean risk, and member reconstruction error are three distinct quantities.

The candidate minimizes the fixed scalar

$$L_{\rm direct}=L_{\rm native}/u_{\rm native}+\frac13\left(\widehat S_{\rm State}/u_{\rm State}+\widehat S_{\rm Scale}/u_{\rm Scale}+\widehat S_{\rm Shape}/u_{\rm Shape}\right).$$

Fit the positive outer units once on matched SOURCE TRAIN800: $u_{\rm native}=\max(\mathbb E L_{\rm native,0},10^{-8})$ and $u_k=\max(\mathbb E|\widehat S_{k,0}^{\rm per\ condition}|,10^{-8})$, averaging absolute per-condition scores rather than the absolute batch mean, with the shared SOURCE query law and existing inner coefficients; freeze these units before estimator comparison and use those same units when comparing query grouping, because its per-condition marginal target is unchanged. Preserve signed scores; do not clip them to zero. Record whether a floor is active; an effectively zero component requires checking the observable before learning rather than silently amplifying numerical noise. Reuse suitable existing SOURCE outputs and reference transforms. These outer units are separate from frozen assessment normalizers and cannot change reported improvement units. No outer-weight or family-dropout search is included.

The ordinary control minimizes the same $L_{\rm native}/u_{\rm native}$ with matched native draws and condition visits. Accumulate the candidate's losses in the explicit order native, State, Scale, Shape, then call backward once. The native branch still requires its own velocity evaluation; it is not free. The SSS endpoint graph is shared across the summed family losses, avoiding three separate full-parameter family VJPs plus the old constraint VJP. This changes the optimizer objective; it is not an exact or conflict-free ConFIG acceleration. Individual families may increase on a stochastic action; the aggregate and final family guards must be measured separately.

Add an explicit training-policy route. Do not enable this by setting a native weight in an external-policy configuration that skips native loss. Relevant entry points are `training/post_training.py` around the native-loss branch, `config/validate.py` around external-policy constraints, and `training/fidelity_budget.py` around `ExternalPolicy.update_with_coherence_aggregation`, all under `src/phycoflow_reconstruction/`. Native FFM is implemented in `models/flows/pointcloud/adapters/gl_rbf_cq_adapter.py::training_loss` and `models/flows/pointcloud/core/portable_core.py`. Preserve legacy routes and historical configurations. The native `training_loss(batch)` currently samples prior/time through global RNG without an explicit generator; add narrow bridge-RNG access or scoped state handling so native draws can remain coupled between arms. Qualify peak memory for the combined native and endpoint graphs: native query microbatching retains graphs until backward and is not covered by rollout checkpointing. Prefer exact checkpointing of that native forward if needed. If the joint graph still cannot fit, permit mathematically equivalent sequential accumulation of the native gradient and the summed SSS gradient under the same frozen scalar and inputs, with one optimizer proposal; qualify gradients and include the resulting two backwards in the cost. This is a bounded memory repair, not a change to the objective or an assumed speedup.

### 3.3 Finite sampled field safeguard

Keep the frozen Round 3 field allowance $\epsilon_f=0.10M_{f,0}$, where $M_{f,0}$ is positive TRAIN SOURCE member MSE in model units squared. Let $s_f=\max(M_{f,0},10^{-8})$. The signed risk on one batch is

$$\widehat R_f(\theta)=\|\overline X-Z\|_{M,f}^{2}-\frac{\sum_j\|X_j-\overline X\|_{M,f}^{2}}{J(J-1)}.$$

Compute the paired excess $D_f(\theta)=\widehat R_f(\theta;B,\xi)-\widehat R_f(\theta_0;B,\xi)$ with identical condition IDs, observations, physical support/masses, latent members and solver for current and frozen SOURCE endpoints. A fixed population SOURCE limit is not necessarily feasible on every heterogeneous minibatch. The paired comparator makes unchanged SOURCE exactly feasible up to roundoff. A Round 4 bank with fixed 256 observations cannot replace a SOURCE forward under the current fresh observation contract. Cache only genuinely identical immutable input/member identities; assume no cache hits in the forecast.

Bind all three endpoints to the same `differentiable_reconstruction` path, using raw current/candidate parameters and the immutable SOURCE parameter view, identical model mode, and explicit saved member priors or generator states captured after support selection. Run SOURCE and post checks under `no_grad`. An original seed alone may not reproduce a generator already advanced by support selection. Do not substitute ordinary inference `reconstruct`, streamed inference chunks or EMA weights without demonstrated equivalence. The candidate's pre-action endpoint already exists for SSS. Each attempted action adds one no-grad SOURCE J2/four-Euler reconstruction and at most two field-only no-grad post-action reconstructions. These do not compute persistence or additional SSS. Reuse same-action static context only when its parameters and graph identity are still valid; a post-action trainable context must be recomputed at the candidate parameters.

1. Save a transaction for parameters, optimizer moments/counters and EMA. Form one tentative AdamW action and its complete displacement $\Delta$, including decoupled weight decay. Save the tentative optimizer state. Obtain $g=\nabla_\theta L_{\rm direct}$ before clipping. Require $g^\top\Delta<0$ beyond qualified numerical tolerance. A zero action is a recorded no-op. A positive dot product is an ascending direction; shrinking the same displacement cannot repair its first-order sign.
2. Test $\theta+\alpha\Delta$ for $\alpha=1$ and then $1/2$, stopping at the first acceptance. Apply $\alpha$ to the complete displacement. For every field require $D_f^{\rm post}\le\max(\epsilon_f,D_f^{\rm pre})+\tau_f$.
3. Define $V(D)=\sum_f[D_f-\epsilon_f]_+/s_f$ and $\tau_V=\sum_f\tau_f/s_f$. If $V(D^{\rm pre})>\tau_V$, additionally require $V(D^{\rm post})<V(D^{\rm pre})-\tau_V$. This restoration condition is not triggered by roundoff-sized violations. Numerical tolerances are fixed from deterministic replay precision before freeze, must be negligible relative to allowances, and must not be expanded to admit updates.
4. On acceptance, commit the chosen parameters and tentative moments/counters exactly once; update EMA once from accepted parameters. A half action is a scaled proposal with the same proposed moments, not a second optimizer step. On rejection, restore parameters, moments, counters and EMA. Consume the attempted training condition/query/native-noise draws once. SOURCE/post checks replay private copies of noise without advancing training streams. Never retry a rejected batch indefinitely.

Reuse the transaction mechanics in `training/round2_virtual_probe.py` and the relevant finite-check/rollback pattern in `training/topology_constraints.py`; do not import its full topology controller. Snapshot explicit generators and samplers as well as global RNG. Current `ScalableCoherenceRuntime.finish_step(False)` restores its query sampler/cursor, and the current trainer raises on a rejected action. The new policy must explicitly separate a valid consumed-but-rejected attempt from numerical failure and from accepted optimizer/EMA advancement, retaining legacy behavior for legacy policies. Otherwise the first intentional rejection would terminate training or repeat its query. An all-field filter can reject conflicting actions; record this honestly. It supplies **sampled feasibility/restoration**, not held-out or full-support feasibility. It does not guarantee each SSS family descends. Population field retention and final scientific usefulness remain authoritative.

The native control has no expensive endpoint filter. Therefore the comparison is the practical package comparison stated above. Do not call it an isolated test of SSS weighting or add a third arm to compensate.

## 7. Generality and paper implications

Core code owns native-objective access, endpoint/member semantics, finite-observable evaluation, query coupling and transactional action checks. A model adapter supplies the native supervised objective and valid reconstruction; a case supplies fields/units, geometry/masses/masks, observations, fixed allowance and an unoptimized scientific question. No CO, temperature, combustion threshold or physical GPU identifier belongs in the generic optimizer. Exact CQ context reuse is an adapter capability; other adapters may execute the same learning contract without that optimization. The current cubical Shape implementation has a declared raster/geometry applicability boundary; do not advertise arbitrary-mesh support without an appropriate provider.

The paper claim, if supported, is: a finite family of interpretable coupled-field observables, directly supervised alongside the native task and constrained by measured field retention, can improve selected scientific relationships at practical post-training cost. The novelty must be supported by relationship gain beyond ordinary continuation and honest computation accounting. Do not claim a universal optimizer, exact LPC realization, complete physical validity, or generic cross-model efficacy from one FFM/combustion experiment. A failed learned package still leaves useful evidence about finite-query noise, actual optimizer actions and exact execution reuse; it does not itself support an enhancement claim.
