# Coherence Adaptive Repair plans

## Link scope

Links within this collection and to the curated report collection are repository-relative. Links marked **local-only** point to original campaign sources, histories, configurations, figures or assessment evidence at their existing host aliases; these artifacts are not included in the reading copies and require the original local storage. Historical fenced commands and literal paths remain unchanged and may depend on that environment. The files are a reading aid; use the original source identities for provenance.
